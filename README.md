## Overview

Luxe Magnate is a full-stack, luxury e-commerce and consultation platform designed to deliver an unparalleled digital experience. It seamlessly integrates a sophisticated storefront, an intelligent AI chat assistant, secure payments, and a beautifully crafted, high-end user interface tailored for premium products and exclusive services.

## Tech Stack

- **Frontend:** React, Tailwind CSS, Radix UI, TanStack Router / Start
- **Backend/API:** Node.js, Vite SSR
- **Database & Auth:** Supabase (PostgreSQL, Authentication)
- **Payments:** Stripe Checkout & Webhooks
- **AI Integration:** Google Gemini AI

## Features

- 🛍️ **Premium Marketplace:** High-end product catalog featuring a meticulous, luxurious UI.
- 🤖 **AI Concierge:** Real-time, intelligent AI chat assistant providing personalized support for premium users.
- 💳 **Secure Checkout:** Full Stripe integration for frictionless and secure payment processing.
- 🔐 **Authentication:** Robust, secure login and user identity management via Supabase.
- 📊 **Dashboard & User Portal:** Elegant user dashboard for managing orders, billing, and subscription tiers.
- 💰 **Financial Calculator:** Built-in interactive financial planning tools with dynamic, responsive charts.

## Setup Instructions

1. Clone the repository
2. Run `npm install` to install dependencies
3. Set up your `.env` variables for Supabase and Stripe
4. Run `npm run dev` to start the development server
